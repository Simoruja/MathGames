# Mystery Math Arcade

Three math games in one page, created by Simoruja.

- **Mystery Box Algebra** (`#algebra`): algebra and multiplication
- **Fair Share Bakery** (`#fractions`): division and fractions
- **Number Blitz** (`#blitz`): addition and subtraction

It's a single static `index.html` with no build step. Progress is saved in each player's browser.

Live site: https://mystery-math-arcade.vercel.app
